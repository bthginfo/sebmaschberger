# Sebastian Maschberger

Eigenständiges Website-Projekt auf Basis von [Website Starter](https://github.com/bthginfo/website-starter), Version 1.37.1.

Das verbindliche Projektbriefing steht in [project/brief.json](project/brief.json). Einstieg und Architektur: [START-HERE.md](START-HERE.md).

`npm ci` installiert die Abhängigkeiten. `npm run setup` richtet einen eigenen Erstzugang ein, `npm run dev` startet die lokale Vorschau.

Vor dem öffentlichen Start: [Startprüfung](docs/launch.md).
